# FastAPI application 

A simple Student Management REST API built using **FastAPI** and **Python** with MVC architecture.

## Features
- Create a student
- View all students
- View student by ID
- Update student details
- Delete a student

## Tech Stack
- Python 3.11
- FastAPI
- Uvicorn
- Pydantic
- Docker
- GitHub Actions
- Render
